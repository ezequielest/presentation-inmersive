# Effilms — Real Estate Visualization Landing

Landing responsive desarrollada con React + Vite, CSS propio y componentes independientes por sección.

## Requisitos
- Node.js 18 o superior
- npm

## Instalación
```bash
npm install
npm run dev
```

Para compilar:
```bash
npm run build
```

## Estructura
- `src/App.jsx`: composición general.
- `src/components/Navbar.jsx`: navegación.
- `src/components/Hero.jsx`: portada.
- `src/components/Marquee.jsx`: banda tipográfica.
- `src/components/Manifesto.jsx`: presentación de Effilms.
- `src/components/Capabilities.jsx`: IA, Gaussian Splatting e inmersividad.
- `src/components/Workflow.jsx`: proceso integrado.
- `src/components/Applications.jsx`: aplicaciones comerciales.
- `src/components/Contact.jsx`: llamada a la acción.
- `src/components/Footer.jsx`: pie de página.
- `src/styles.css`: estilos globales, responsive y animaciones.

## Antes de publicar
1. Reemplazar las imágenes de referencia por material propio de Effilms.
2. Cambiar `hola@effilms.com` por el correo comercial definitivo.
3. Conectar el CTA a WhatsApp, CRM o formulario de contacto.
4. Revisar textos, portfolio, logos y casos reales.
